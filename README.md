# Sample legal knowledge base (fictional)

Sample content for testing [Enterprise Knowledge Sharing](https://github.com/anubhav247/enterprise-kb-mcp).

**Everything here is fictional.** "Meridian Freight Systems Pvt Ltd", its people,
email addresses, amounts and policies are invented. Nothing here is legal advice.

## Layout

| Path | Contents |
|---|---|
| `knowledge-base/` | Legal team documents. Each has front matter: `title`, `category`, `owner`, `tags`, `last_reviewed`. |
| `mcp/instructions.md` | How an assistant should use this knowledge base |
| `mcp/prompts/` | Reusable prompts for common legal questions |
